# 📦 Parcel FIFO Tracking System (Refactored)

이 프로젝트는 컨베이어 벨트 위를 이동하는 택배(Parcel)를 여러 대의 카메라에서 끊김 없이 추적하기 위한 통합 솔루션입니다. YOLOv8의 검출 능력과 FIFO(First-In-First-Out) 기반의 물리적 매칭 알고리즘을 결합했습니다.

---

## 📂 프로젝트 구조 및 역할

| 파일명 | 역할 설명 |
| :--- | :--- |
| **config.py** | 시스템의 '뇌'입니다. 모든 ROI 좌표, 카메라 간 이동 시간, 오차 범위(Margin)를 관리합니다. |
| **loader.py** | 분산된 이미지 파일들을 타임스탬프 기준으로 정렬하여 하나의 '시간 스트림'으로 합칩니다. |
| **matcher.py** | 물체가 카메라 사이를 넘어갈 때 마스터 ID를 인계(Handoff)하는 핵심 로직을 담당합니다. |
| **utils.py** | 시간 변환($hhmmss \rightarrow sec$) 및 결과 비디오 저장을 돕는 도구 모음입니다. |
| **main.py** | 전체 엔진을 가동합니다. 프레임별 Detection, 로컬 트래킹, 글로벌 매칭을 실행합니다. |

---

## ⚙️ 핵심 로직 상세 설명

### 1. 전역 타임라인 동기화 (Global Sorting)
각 카메라가 찍은 시점은 제각각이지만, 택배의 이동은 절대적인 시간 흐름을 따릅니다. 
- 파일명에서 `20250127_082000_123` 형태의 시간을 추출합니다.
- 이를 초(seconds) 단위로 변환($3600h + 60m + s + ms$)하여 모든 카메라의 프레임을 시간순으로 정렬합니다.

### 2. 로컬 트래킹 (Intra-Camera Tracking)
프레임 사이에서 동일한 물체를 식별하기 위해 다음 공식을 사용합니다:
- **X축 거리**: $dx = |cx_{new} - cx_{old}|$ (벨트 폭 내 움직임 제한)
- **Y축 방향성**: $dy = (cy_{new} - cy_{old}) \times \text{forward\_sign}$
- `forward_sign`이 `-1`이면 좌표가 작아지는 방향이 '전진'임을 의미하며, 역주행하는 물체는 트래킹에서 제외합니다.

### 3. FIFO 기반 글로벌 매칭 (Inter-Camera Matching)
컨베이어의 물리적 특성상 물체는 **"들어온 순서대로 나갑니다."**
- **Master 생성**: 첫 번째 카메라에서 물체가 발견되면 `MASTER_001`을 생성하고 `q01` 큐에 넣습니다.
- **예상 시간 계산**: 다음 카메라에 물체가 나타나면 큐의 맨 앞(가장 오래된) 마스터를 꺼내어 아래 조건 확인:
  $$|CurrentTime - (LastPassTime + AVG\_TRAVEL)| < TIME\_MARGIN$$
- 이 조건이 만족되면 ID를 이어받고 다음 구간 큐로 이동합니다.

### 4. 가상 EOL (End of Line) 감지
마지막 카메라(`RPI_USB3`)는 두 개의 가상 영역을 가집니다.
- **XSEB 영역**: 벨트 위를 지나가는 물체를 트래킹합니다.
- **EOL 영역**: 최종 배출 지점(End of Line)에 도달했는지 판단하여 마스터 이벤트를 최종 기록합니다.

## 🚀 실행 방법
1. `config.py`에서 `BASE_DIR` 및 `MODEL_PATH`를 본인 환경에 맞게 수정합니다.
2. `main.py`를 실행합니다.
3. `Parcel_Integration_Log_FIFO/` 폴더에서 결과 영상과 CSV 로그를 확인합니다.
